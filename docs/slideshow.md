# 当前范围幻灯片

需求与验收见 [需求文档](requirements/slideshow-enhancement.md)；本次实际验证见
[交付报告](reports/slideshow-enhancement.md)。

## 操作

- 照片详情：确定启动；运行中确定暂停，再确定继续。照片暂停后重新计算完整间隔。
- Menu 打开设置：照片间隔 3/5/10/15/30 秒，循环当前范围、播放视频开关。
  默认 5 秒、循环关、视频开；三个选项在设备本地保存，播放中状态不保存。
- 视频：上下/Menu 打开原操作栏，其中“幻灯片”可配置并开始。幻灯片运行时 Menu
  直接打开设置；视频方向键仍定位，手动定位/切媒体退出幻灯片。
- 打开设置会暂停；“关闭”只关闭面板，不自动续播。“继续播放”或确定显式恢复。
  视频操作栏的播放/暂停与幻灯片会话协调，暂停必须停止实际视频帧推进。
  视频已结束且等待分页时暂停，继续后进入下一项，不从头重播已结束的视频。
- Back 先关闭设置；详情 Back 退出到列表。Home/后台停止自动推进，返回不恢复幻灯片。
  被跳过或停止自动播放的视频不会因无缩略图而在返回时自动开播，确定可手动播放。

## 内容与循环

从当前媒体起播，照片主图请求成功或失败后开始所选间隔；缩略图完成不提前计时。
开启视频时播至结束再换下一项；关闭时跳过视频，不请求其视频流。
连续跳过175项后暂停，需明确继续；原来源的五页元数据扫描预算仍保留。

循环回当前范围首项，而不是当前驻留窗口首项。主照片墙复用原查询/排序/权限和
已知接口，重新请求原始 offset=0，仍保留 560 原始行/16页窗口、561项详情上限。
重启结果先暂存，只有仍运行或用户显式继续才替换详情内容。过程中失败保留当前媒体，
不会把不完整状态当结束；返回列表仍按媒体ID定位。

搜索/文件夹仅确认从offset0完整载入且无边界/错误时循环；后续批、超限或其他不完整来源
明确提示不支持，不把当前批冒充整个列表。进程死亡恢复的缺分页源快照也不支持完整范围循环。
有限、完整且无分页源的列表可本地循环；单图可静态展示或按设置循环。

全部视频且禁视频时会停止并显示明确未播放状态，不无限空转。图片失败延续原提示/推进行为；
视频错误/分页失败停止自动播放，保留现有手动重试。没有随机播放、全图库预载或新NAS参数。

## 代码与验证边界

`SlideshowState` 管理配置/会话/有界跳过；`MediaDetailActivity` 管理计时、遥控、播放器和生命周期；
`MediaPageController` 与 list-owned `PageSource` 管理受控范围重启。
`SlideshowStateTest`、`SlideshowRestartTest` 为JVM状态/合同测试；`SlideshowDeviceTest`
为合成设备实际Activity测试，不证明真实NAS。

NAS的数据变化仍受offset分页一致性限制；共享撤权、真实Range/鉴权、真实TV解码须另行验证。
不放宽普通/共享传输差异、凭据重定向限制或API19/Java8约束。
